# bmad-distilled

A distilled, markdown-first BMAD toolkit for AI-assisted product, architecture, engineering, and testing workflows.

This repository turns BMAD into a lightweight virtual team of specialist roles that can be dropped into project documentation and used to guide AI agents through planning, design, implementation, review, and testing.

## How it is used

- Put it in the docs of a project so the AI can reference it as part of the project context.
- Use it when a prompt needs a specialist role in software development, such as architect, PM, developer, tester, or UX designer.
- Use it to spawn a small team of agents and let them collaborate across roles to solve harder problems.

See [distilled/README.md](distilled/README.md) for the full guide and usage patterns.
